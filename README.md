# Obi Praise Chinedu - Portfolio

A personal portfolio website showcasing my work as a Full-Stack Product Engineer with a strong emphasis on frontend design and UX.

## Overview

This is my personal portfolio project - a multi-page website that showcases my projects, skills, and professional background. It demonstrates proficiency in:

- Semantic HTML & accessibility
- Modern CSS with custom properties and responsive design
- Vanilla JavaScript for interactivity
- Full-stack development with React, FastAPI, Python
- AI integration (Groq/LLaMA)

## Getting Started

To view this portfolio locally:

1. Clone the repository
2. Open `index.html` in your browser
3. Or serve with a local server:

Then visit `http://localhost:8000`

## Customization

To customize this portfolio for your own use:

1. Replace `assets/images/profile.jpg` with your photo
2. Update links in navigation to point to your pages
3. Modify the content in each HTML file
4. Update meta descriptions and titles
5. Change color scheme in `styles.css` CSS variables
